# 🛍️ Telegram Mini App — Интернет-магазин & Бот-витрина

Полнофункциональный интернет-магазин внутри Telegram (Telegram WebApp / Mini App) с панелью администратора, базой данных SQLite, автоматическими уведомлениями и инлайн-действиями в Telegram-боте.

---

## 🌟 Основные возможности

### 📱 Для покупателей (Telegram Mini App):
* **Главная витрина:** стильный интерфейс с баннером, категориями и популярными товарами.
* **Каталог и Поиск:** удобная фильтрация по категориям и мгновенный поиск по названиям и вкусам.
* **Карточка товара:** поддержка нескольких вкусов/вариантов с раздельным учетом остатков на складе, ценой и фото.
* **Корзина и Оформление:** добавление позиций с контролем остатков, комментарий к заказу.
* **Экран подтверждения:** номер заказа, итоговый чек и кнопка прямой связи с менеджером.
* **Тёмная и светлая тема (🌙 / ☀️):** автоматическое определение темы Telegram + кнопка ручного переключения.

### 🔔 Для администратора в Telegram:
* **Мгновенные уведомления:** при создании заказа бот сразу присылает сообщение с деталями: номер, покупатель (@username / ID), состав, сумма и комментарий.
* **Инлайн-кнопки:** кнопка **«💬 Написать клиенту»** прямо под заказом для быстрого открытия диалога.

### ⚙️ Панель управления (Admin Panel):
* **Вход по секретному ключу** (`ADMIN_TOKEN`).
* **Товары:** создание, редактирование, загрузка и замена фотографий (JPG/PNG/WebP до 5 МБ), настройка вкусов/вариантов и складских остатков.
* **Категории:** управление структурой каталога, иконками и сортировкой.
* **Заказы:** просмотр списка заказов, смена статусов (*Подтверждён*, *Выполнен*, *Отменён*). При отмене заказа товары **автоматически возвращаются на склад**.
* **Настройки брендинга:** изменение названия магазина, слогана, описания и Telegram-контакта менеджера прямо из интерфейса.

## 🚀 Быстрый старт (Локальный запуск)

### Требования:
* **Node.js 22+** (проект использует встроенную базу данных `node:sqlite`).

### 1. Установка зависимостей:
```bash
npm install
```

### 2. Настройка переменных окружения:
Создайте файл `.env` в корне проекта (скопируйте из `.env.example`):
```env
PORT=3001
ADMIN_TOKEN=my_super_secret_admin_key
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
ADMIN_TELEGRAM_IDS=5224947292
```

### 3. Запуск в режиме разработки:
В первом терминале (сервер API + база данных):
```bash
npm run dev:api
```
Во втором терминале (Vite фронтенд):
```bash
npm run dev
```

Магазин откроется по адресу: `http://localhost:5173`
Панель администратора: `http://localhost:5173/#admin`

## 🌐 Развертывание на хостинг (BotHost, VPS, Cloud)

В продакшене проект запускается как единый сервис (Express сам раздает и API, и скомпилированный React-фронтенд):

### 1. Сборка фронтенда:
```bash
npm run build
```

### 2. Запуск сервера:
```bash
npm start
```
Сервер будет слушать порт, переданный хостингом в переменной `PORT` (или `3001` по умолчанию).

## 🤖 Настройка Telegram-бота в @BotFather

1. Откройте диалог с [@BotFather](https://t.me/BotFather) в Telegram.
2. Создайте нового бота командой `/newbot` или выберите существующего.
3. Скопируйте полученный **API Token** в поле `TELEGRAM_BOT_TOKEN` в `.env`.
4. Настройте кнопку запуска Mini App:
   - Отправьте команду `/setmenubutton`.
   - Выберите вашего бота.
   - Введите текст кнопки (например, `🛍 Открыть магазин`).
   - Укажите HTTPS-ссылку на ваш сайт (например, `https://ваш-проект.bothost.ru`).
